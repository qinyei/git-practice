# 计算器（Git 练习版）

这是 `实验1 · 带键盘事件的计算器` 的**迷你练习工程**，只用来演练 Git 操作，不追求功能完整。

## 文件说明

| 文件 | 作用 |
|---|---|
| `calc.h` / `calc.cpp` | 四则运算的核心逻辑 |
| `main.cpp` | 临时测试入口 |
| `calculator.pro` | Qt 工程文件（本练习不编译） |
| `.gitignore` | 告诉 Git 哪些文件**不要**跟踪 |
